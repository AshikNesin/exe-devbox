Why exebox

Batteries included

Every painful manual step from the multi-project setup — automated, idempotent, and production-tested.

🔌

Auto DNS

Detects Cloudflare and creates the CNAME automatically via the exe.dev proxy or your API token. Manual instructions for everything else.

🔥

HMR that works

Sets VITE_HMR_URL to your public domain so hot module replacement flows through exe.dev + nginx without a single WebSocket error.

🏠

Smart defaults

Set --default-domain once, then just pass a project name. exebox derives the FQDN and wires the whole chain.

📡

Push notifications

Get notified on your device when a domain is added, a dev server starts, or setup completes. Silent if unavailable.

🩺

Health checks

exebox doctor validates reflection, dependencies, services, and ports — so you know the stack is healthy at a glance.

🔄

Idempotent

Every command is safe to re-run. setup, new, and dev clean up after themselves and settle into the right state.
